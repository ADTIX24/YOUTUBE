# وكيل صناعة القصص التلقائي (Vercel Ready)

هذا المجلد جاهز بنسبة 100% للرفع المباشر على منصة **Vercel** مجاناً دون الحاجة لكتابة أي كود أو تنزيل بايثون ومكتبات على جهازك.

## 📁 محتويات المجلد:
1. `index.html`: واجهة التحكم الرسومية التي تفتحها في المتصفح.
2. `vercel.json`: ملف التوجيه التلقائي لمسار `/api/run`.
3. `requirements.txt`: يخبر Vercel بتثبيت `google-genai` و `beautifulsoup4` و `requests` في السحاب.
4. `api/run.py`: السكربت السحابي الذي يعالج القصة، يفرغ حقوق الملكية، ويولد السيناريو ومشاهد الصور بالذكاء الاصطناعي.

## 🚀 طريقة الرفع على Vercel:

### الطريقة الأولى (عبر GitHub - الأسهل والأسرع):
1. قم بإنشاء مستودع جديد (Repository) على حسابك في GitHub.
2. ارفع هذا المجلد أو ملفاته الأربعة إلى المستودع.
3. ادخل إلى موقع [Vercel](https://vercel.com)، واضغط **Add New Project**.
4. اختر المستودع الخاص بك واضغط **Deploy**.
5. سيعطيك Vercel رابطاً مباشراً يمكنك فتحه من الهاتف أو الكمبيوتر في أي وقت!

### الطريقة الثانية (عبر سطر الأوامر Vercel CLI):
```bash
npm i -g vercel
cd my-video-agent
vercel
```
ثم اتبع الخطوات البسيطة وستحصل على الرابط الفوري.
