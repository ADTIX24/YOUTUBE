# حزمة تشغيل الوكيل على Vercel (الصيغة الرسمية الأصلية المباشرة)

هذه الحزمة مطابقة 100% للهيكل الإجباري لمنصة **Vercel** بدون أي مكاتب وسيطة معقدة لضمان عدم ظهور أخطاء `404 Not Found` أو `Timeout`.

---

## 📁 هيكل الملفات في المشروع:
```plaintext
my-project/
├── index.html
├── vercel.json
├── requirements.txt
└── api/
    └── run.py
```

---

## ⚙️ تفاصيل الملفات الأساسية:

### 1. `vercel.json`
```json
{
  "functions": {
    "api/run.py": {
      "runtime": "python@3.11",
      "maxDuration": 60
    }
  }
}
```
> **ملاحظة:** تم ضبط `maxDuration: 60` ثانية لمنع انقطاع الاتصال (Timeout) أثناء معالجة وصياغة القصة بواسطة Gemini.

### 2. `requirements.txt`
```plaintext
google-genai
requests
beautifulsoup4
```

### 3. `api/run.py`
مبني على كلاس `BaseHTTPRequestHandler` الأصلي المدعوم من Vercel مباشرة:
- يستقبل طلبات `POST` على `/api/run`.
- يستجيب لطلبات `GET` برسالة تأكيد لسهولة اختبار الرابط في المتصفح.
- يدعم استقبال رابط القصة أو نصها المباشر.
- يغير الشخصيات والمعالم ويوزع الأحداث على المشاهد المحددة بدقة.

---

## 🚀 طريقة التشغيل خطوة بخطوة:

### الخطوة 1: رفع الملفات على GitHub
1. أنشئ مستودعاً جديداً (New Repository) على GitHub.
2. ارفع الملفات الأربعة بحيث تكون **مباشرة في الجذر (Root)**:
   - `index.html`
   - `vercel.json`
   - `requirements.txt`
   - مجلد `api` وبداخله `run.py`.

### الخطوة 2: الربط مع Vercel
1. ادخل على [vercel.com](https://vercel.com) وسجل الدخول.
2. اضغط **Add New...** ثم **Project**.
3. اختر المستودع الخاص بك واضغط **Deploy**.

### الخطوة 3: التحقق الفوري من إزالة خطأ 404
افتح متصفحك واكتب رابط مشروعك مع إضافة `/api/run`:
```text
https://اسم-مشروعك.vercel.app/api/run
```
إذا ظهرت لك هذه الجملة:
> **مسار الـ API يعمل وجاهز لاستقبال الـ POST**

فهذا يعني أن مسار الـ Serverless تم تفعيله بنجاح 100% وبدون أي مشاكل!
الآن افتح رابط موقعك الرئيسي وضع مفتاح Gemini وابدأ بتوليد سيناريوهاتك فوراً.
